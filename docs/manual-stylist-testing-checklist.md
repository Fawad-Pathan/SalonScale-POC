# Manual Stylist Testing Checklist

- Was the user able to open the scanner?
- Was the user able to take or upload a photo?
- Were products identified?
- Were counts understandable?
- Could incorrect results be edited?
- Could the scan be completed?
- Was the completed scan visible in history?
- Did the user understand how to use the application?
- How long did the scan take?
- What feedback did the stylist provide?
